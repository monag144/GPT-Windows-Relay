- PowerShell/.NET on this relay runtime does not expose the static method `System.Security.Cryptography.RandomNumberGenerator.GetInt32`.
- The generated-password routine therefore failed during its first random-character selection.
- Relay error: `MethodNotFound` for `GetInt32`.

State impact:

- No credential file was written.
- No email/password values were entered into Workday.
- The `Create Account` button was not invoked.
- The anti-bot honeypot was not touched.

Engineering lesson:
- Do not assume modern static cryptographic RNG helper methods are available in the PowerShell/.NET runtime used by the Windows relay.
- Prefer a compatibility-safe byte-oriented cryptographic RNG implementation and derive bounded character indexes from generated bytes.
- Keep secret values absent from stdout and GitHub regardless of generator implementation.

Recovery:
- Retry from the unchanged Create Account page using the compatibility-safe generator.
