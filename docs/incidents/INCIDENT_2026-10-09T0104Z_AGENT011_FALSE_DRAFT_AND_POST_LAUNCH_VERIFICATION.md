## Definitive root cause
Firefox UIAutomation ValuePattern and TextPattern for the Edit named `Ask ChatGPT` return exact `"Ask ChatGPT\n"` (12 characters) in both the previously targeted PCE11 source conversation and a newly opened, untouched ChatGPT home page. Both source offscreen editor representations and the home foreground editor report this same exact value, and the home has no visible enabled Send button. Prior code incorrectly used `-not [string]::IsNullOrWhiteSpace([string]$vp.Current.Value)` and classified that accessibility placeholder as user-authored content; PCE11.037 worker halted safely at `HALT_BEFORE_CLICK SOURCE_COMPOSER_HAS_DRAFT`. PCE11.049 classified the exact placeholder with `value_equals_ask_plus_lf=true`, trimmed length 11, no raw content export. Do not generalize this observation to arbitrary user content or delete any non-matching editor text. Safe predicate must accept ONLY exact recognized placeholder or truly whitespace empty, never lowercase trim of arbitrary message.

## Separate-window attempt and verification fault
PCE11.045 was a one-shot Windows Relay action that ran `Start-Process firefox.exe --new-window https://chatgpt.com/` after governance and source gates. The worker wrote `launch_invoked=true` and terminated `HALT_AFTER_LAUNCH_NO_RETRY` with PowerShell error `Cannot convert the "System.Object[]" value of type "System.Object[]" to type "System.Int64".` The classification is verified by the receipt `LOCALAPPDATA/GPTWindowsRelay/ops/PCE11_045_AGENT011_SEPARATE_WINDOW_LAUNCH.json`, and that packet MUST NOT be replayed. The fault was in the follow-up PowerShell UIA verification, not proven to be a browser launch failure. PCE11.046 read-only reconciliation found **two** distinct visible Firefox windows, both PID 5440: original PCE11 source URL with 11 TabItems and new home `chatgpt.com` with 1 TabItem. No browser or editor action performed in .046. An initial source draft check falsely reported absent because it filtered only visible (offscreen=false) editors when original window was background; PCE11.047-.049 correctly observed offscreen source editor values without selecting or changing it.
